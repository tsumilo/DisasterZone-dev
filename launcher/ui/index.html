      Check for updates on start

      BACKGROUND
      Keep running in the tray
      Closing the window keeps the launcher in the tray. It checks for a new release every 5 minutes and tells you when one is out.
      Install updates by itself
      Installs a new release in the background while World of Warcraft is closed, and tells you when it's done. The launcher updates itself the same way.
      Start with the computer
      Starts quietly in the tray when you log in.
      PLAY
      Battle.net launch code

      DISCORD
      Guild Discord syncNot linked.
      Show me as in game
      While World of Warcraft runs, the guild's launchers show you under "online now" in their title bar, as the character you played last.
      Link this launcher
      Type /launcher in the guild's Discord and paste the code it gives you. Your game's sign-ups, BiS lists and raids then reach Discord after each save, and what people change in Discord reaches your game at its next login or /reload.
